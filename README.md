## How I work

1. Read the concept, write a note in `notes/` in my own words.
2. Do a lab in `labs/` and commit the manifests and commands that worked.
3. Record problems and fixes in `JOURNAL.md`.
4. Tick the box in `PROGRESS.md` and update the table above.
