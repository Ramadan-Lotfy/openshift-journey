# Lab 01: First deployment on the Developer Sandbox

## Goal
Deploy an app with `oc new-app` and expose it with a Route.

## Steps
1. `oc login --token=<token> --server=<server>`
2. `oc project <my-project>`
3. `oc new-app <image-or-git-url>`
4. `oc expose service/<name>`
5. `oc get route`
